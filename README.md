# Minecraft Crossover

**gta5** × Minecraft · visual · idea by the team

GTA V and Minecraft run live together: Minecraft blocks and creatures appear inside Los Santos and react to the player. The change shows in the first 30 seconds of play.

> I strapped Steve's elytra on and dove off the Maze Bank roof through gold rings over Los Santos. The rocket boosts set off real GTA fireworks.

## Install

Install Fabric for Minecraft Java and put the mod jar in its mods folder, then add the GTA V plugin (MCPassthrough.asi) next to GTA5.exe with ScriptHookV. Start both games offline (GTA story mode), and Steve flies off the Maze Bank roof by himself.
